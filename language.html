Common Terms Used in Chrome OS Discussions (For Skids) 🐳

  • Unenrolling: Most common term referring to removing FWMP (Firmware Management Parameters), which are stored in the TPM (Trusted Platform Module).
  • Downgrading: Refers to reverting to an older version. This is limited by the device's kernver, which can prevent downgrading past a certain version.
  • Kernver: Short for Kernel Version. Determines which versions a device can downgrade to.
