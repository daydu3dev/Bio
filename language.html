Common Terms used in Chrome OS discussions (For skids)🐳

  • Unenrolling: Most common term. Usually refers to removing FWMP which is firmware management parameters that are stored in the TPM (Trusted Platform Module).
  • Downgrading: Refers to the action of reverting to an older version. Can only be done to a certain kernver
  • Kernver: Short for Kernel Version. Determines what version you can downgrade, basically to prevent rollback. Can be bypassed with A Sh1mmer Payload if FWMP is not present and then downgrading to any desired version
